# Data Structures Using C++

This repository contains implementations of Stack, Queue, and Circular Queue using C++ and Object-Oriented Programming concepts. The programs are menu-driven and designed for beginners to understand the working of basic linear data structures through simple console-based applications.

Implemented Programs:
- Stack Implementation
- Queue Implementation
- Circular Queue Implementation

Features:
- Menu Driven Programs
- Push Operation
- Pop Operation
- Peek/Display Operation
- Overflow Handling
- Underflow Handling
- Circular Queue Traversal
- User Defined Size
- OOP Based Implementation
- Beginner Friendly Logic

Technologies Used:
- C++
- Object-Oriented Programming
- Arrays
- Console Application
- Code::Blocks / Turbo C++

Programs Included:

1. Stack Implementation
- Push Elements
- Pop Elements
- Display Stack
- LIFO Implementation
- Stack Overflow & Underflow Handling

2. Queue Implementation
- Insert Elements
- Delete Elements
- Display Queue
- FIFO Implementation
- Queue Overflow & Underflow Handling

3. Circular Queue Implementation
- Circular Insertion
- Circular Deletion
- Display Circular Queue
- Efficient Memory Utilization
- Circular Traversal Logic
